# Delhi-AQI-Data-2025-Analysis-using-Pandas-numpy-Matplotlib-Seaborn-Project
Exploratory analysis of hourly weather and air quality data for Delhi (2025) using pandas, NumPy, Matplotlib, Seaborn, SciPy and scikit-learn. 17 charts, CPCB AQI recomputed from PM2.5, estimated GRAP days, and clustering of Delhi's day types.
